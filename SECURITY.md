# Security Policy

## Supported versions

Only the latest published release and the `main` branch receive security fixes.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability-reporting feature for this repository when available. Include a reproducible description, affected file or version, impact, and any safe proof of concept. Do not include credentials, private inventories, or personal data.

This project is a static client-side application and intentionally has no production secrets or authenticated backend. Reports involving unsafe import handling, cross-site scripting, path/payload abuse, privacy leakage, or unsafe build/deployment behavior are especially welcome.
